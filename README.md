# マッチョクラブ

筋トレを記録すると、自分の分身のボクサーが鍛わっていく、自分用のアプリです。iPhone のホーム画面に置く Web アプリ（PWA）で、記録は端末の中（localStorage）だけに残ります。

- 種目・重さ・回数・セット数を記録すると、パンチ力・ガード・スピード・体力が伸び、体つきが締まっていきます
- 能力の組み合わせで技を覚え、技を3つ持ち込んで、アメリカのリングで次々に現れるボクサーと自動で戦います
- 勝って稼いだお金で、トレーニング用具・部屋の内装・服を買えます
- 同じ端末の「ねむりの庭」に今朝の睡眠があれば、試合のコンディションに使います
- 素の HTML / CSS / JavaScript（ES モジュール）。ライブラリもビルドもありません
- 登場するボクサー・会場・看板はすべて架空です

## 手元で動かす（このフォルダの一つ上から）
```
python kintore/tools/serve.py 8124
```
- アプリ：http://localhost:8124/
- ルールのテスト：http://localhost:8124/tests/rules.test.html
- 開発用パネル：http://localhost:8124/?dev=1（体つき・休んだ日数・部屋の見た目だけを切り替えます。記録は変わりません）
- 相手の強さの釣り合い：http://localhost:8124/tools/balance.html
- 絵の総点検：http://localhost:8124/tools/check-art.html
- アイコンを作り直す：http://localhost:8124/tools/make-icons.html（絵は `src/art/icon.js`）

`tools/serve.py` はブラウザに古いファイルを覚えさせない静的サーバーです（ふつうの `python -m http.server` でも動きます）。

## iPhone に入れる
1. iPhone の Safari で公開先の URL を開き、共有ボタン →「ホーム画面に追加」
2. ホーム画面のアイコンから開く。ブラウザのタブとは記録が別々なので、ふだんはホーム画面から
3. 機種変更などに備えて、記録帳 → 設定 →「書き出す」でときどき控えをとる

Service Worker は HTTPS か localhost でしか動かないため、オフラインで使うには HTTPS の場所（GitHub Pages など）に置きます。

## オフラインのしくみ（sw.js）
- 電波がないときは、すぐキャッシュから開きます
- 電波があるときは最新を取りに行き、3秒で返事がなければキャッシュを使います
- Google Fonts は一度取ったらキャッシュを使います
- ファイルを増やしたら `sw.js` の `APP` に足し、`VERSION` を上げる
